# Moving Head Studio

Local fixed-view visual editor for `MovingHeadSequencer`.

```powershell
dotnet run --project tools/MovingHeadSequencer.Web -- --workspace-root .
```

The host listens only on localhost, opens the default browser, and keeps sequence data on the local machine. Use `--no-browser` for automated runs.

Use the top-bar **Workspace…** command to switch sequence folders while the app is running. Enter an absolute path or use the operating-system **Browse…** picker. A replacement workspace is accepted only after it yields a valid sequence document; an invalid or empty folder leaves the current workspace untouched. The selected folder is stored in the current user's local application-data directory and is reused on future launches. An explicit `--workspace-root <path>` remains the highest-priority startup override. Projects, backups, staging files, generated outputs, and sequence discovery all move with the active workspace.

The Heads input accepts any whole number from 2 through 12. Even layouts retain mirrored center pairs; odd layouts use one true center fixture. Dense previews scale fixture glyphs to fit while generated DMX values retain the full calibrated range.

At startup, the Sequence menu scans top-level `.xsq` files in the workspace. Invalid files and generated `-2MH` through `-12MH` outputs are omitted; repeated song titles include the source filename. Storm and Lil Jon retain their specialized choreography definitions. Sequences with aggregate `MH Pan`, `MH Tilt`, `MH Dimmers`, and `MH Shutters` controls import those tracks into the editor. Other sequences open with their original duration, timing tracks, phrases, and media metadata plus a neutral parked/dark moving-head cue ready for editing.

Selecting a sequence and head count automatically opens its hidden editor project from `.moving-head-sequencer/projects/`; the first open creates one after successful validation. Every later successful compile auto-saves cue data, fixture profile, timing source, output name, preview calibration, selected cue, and regeneration attribution through an atomic versioned `.mhproj` file. Projects are isolated by source path and head count, and prior revisions are archived. Revision tokens prevent an older browser tab from overwriting a newer project; the stale tab reports that it must reload. If xLights changes the source XSQ, the editor asks whether to keep/relink the saved project or archive it and rebuild from the sequence. The **Project** menu is an advanced portability surface: import or export a versioned `.mhproj` copy, or rebuild from the sequence. Bare cue-sheet JSON is not accepted.

Aggregate-control import decodes DMX holds, ramps, ramp-up/down curves, repeated saw-tooth curves, per-node On levels/fades, and shutter windows. Source nodes are distributed evenly across the selected 2–12 preview heads; select the source head count for one-to-one playback. Model-level SingleStrand/Shimmer dimmer effects are currently approximated as visible group effects, while per-node intensity remains decoded. Native xLights `Moving Head` path effects without aggregate controls are preserved but are not yet imported.

Imported aggregate pan uses the midpoint of the authored minimum and maximum as its neutral projection center. Opposing source banks therefore render as symmetric left/right beams instead of making one bank appear vertical.

The Canvas preview evaluates the same generated hold, ramp, bounce, and custom shape curves used by the core sequencer. It renders a narrow neutral-white beam; dimmer and shutter are the only beam appearance controls. Color, gobo, prism, and focus programming are intentionally outside the editor. Editing a cue recompiles and validates the complete plan through the .NET engine before the browser accepts it.

The preview defaults to floor-mounted fixtures pointing upward. Open **Fixture setup** from the stage toolbar to switch to overhead **Truss ↓** orientation. This switch is visual only and does not alter XSQ output.

Use **Base yaw · vertical axis** inside Fixture setup to yaw preview fixtures by 0°, 90°, 180°, or 270° around an axis pointing from the floor toward the sky. Its All/Odd/Even/individual selection is independent from cue Fixture scope. Values are stored locally for each sequence and head count. Yaw is intentionally a Canvas calibration and does not rewrite pan/tilt DMX in generated XSQ files.

The right sidebar is a cue inspector: Timing, Fixture scope, Movement, Beam, and Regenerate cue all edit or explain the selected cue. Sequence-wide commands live outside it. **Regenerate song** and regeneration Undo are in the top command bar. **Generate XSQ** opens a focused destination/output dialog; New file notes that its XSQ can be used inside xLights to import moving-head effects into another sequence. The footer validation status opens a read-only sequence-wide metrics/issues drawer; issues overlapping the selected cue also appear inline beneath Timing. Pan and tilt percentages explicitly report time spent moving, and the configured range is reported in DMX units. Sequence-wide 0–255 output boundaries live under **Fixture setup** and use dual-handle sliders. Each endpoint displays its DMX value and calibrated angle. Full physical travel defaults to 540° pan and 270° tilt and is editable from the fixture manual; degree conversion assumes centered pan and zero-at-forward floor tilt, and respects axis inversion. Pan uses a normalized overhead left/forward/right fan, while floor-mounted tilt uses a normalized side-view forward/up/back fan. Cyan shows the allowed sweep and gold rays mark its endpoints. Tightening a boundary constrains profile anchors plus compiled preview/XSQ output, but preserves stored explicit cue curves so widening the range can recover their original motion. Limits and travel calibration persist with the hidden project.

The Generate XSQ dialog defaults to **New file**. Every output is first written to a sibling staging file, reopened from disk, and post-write validated before it can replace its destination. Validation requires the xLights root and core sections, a positive sequence duration, valid EffectDB and palette indexes on every model effect, and persisted generated pan/tilt/dimmer/shutter tracks with the expected fixture count, timing, frame alignment, and duration. A failed check deletes staging and preserves any existing output. Select **Original file** only when the generated choreography should replace the selected source XSQ. The editor additionally verifies that the source has not changed, writes and hash-verifies a timestamped backup under `.moving-head-sequencer/backups/`, then atomically replaces the source. Any external source change aborts replacement. Original backups are listed in the same dialog. **Restore** first backs up the current source version, restores the selected backup without consuming it, and reloads the editor; repeated and reverse restores therefore remain possible.

Pan/tilt progress is preserved when independent dimmer changes divide one movement into several editor cues. Any user edit that creates a discontinuous position is surfaced as a `pan-position-jump` or `tilt-position-jump` validation warning.

Each cue also has a Rhythm selector: Off; a low-position beat lift; half-, one-, or two-beat full-bank tilt; a syncopated tilt pulse; one-by-one, mirrored-pair, odd/even, or center/outer tilt chase; two-beat pan sweep; or four-beat combined pan/tilt orbit. These options compile from the currently selected timing source and are emitted into the generated XSQ exactly as previewed.

Energy scales movement inside each fixture's calibrated profile: Subtle uses 40% of the normal excursion, Medium 70%, Full preserves the authored range, and Extended reaches the validated axis limit. Shape selects Smooth, Punch with a held peak and slower recovery, or Double hit curves. Phase runs fixtures Together, Left to right, Center out, or in Alternating pairs. Base dimmer sets the curve maximum; automatic regeneration uses only All0 or All100. Beam envelope offers Steady, Fade In/Out, full-range Pulse, Turnaround, source Flash (`0→0→100→0`), Rise and Hold (`0→100→100→100`), and Opalite-derived Textured Pulse (`0→0→7.5→100→60.625→100→100→0`). Older intermediate base levels remain available for imported cue sheets and manual editing. All generated boundaries remain aligned to the source sequence frame grid.

**Fixture scope** identifies every fixture eligible during the whole cue; it does not mean each fixture is active at every instant. A gold underline marks fixtures lit at the current playhead. One-by-one chase advances both movement and intensity through one fixture per beat, while mirrored-pair chase lights only the active outside-in pair. Inactive chase fixtures emit dimmer zero in preview and generated XSQ.

The **Regenerate cue** panel automatically ranks four alternatives for the selected cue: energetic, phrase/balanced, restrained, and rest/dark-transition. Ranking uses phrase labels, cue duration, beat count, concurrent non-mover effects, neighboring mover poses, and recent repetition. Every choice includes confidence, rationale, and source/context evidence. **Apply** updates only the selected cue and recompiles through validation.

The Movement **Source** field identifies where the resolved movement came from. Untouched regenerated cues show `Generated · <effect name>` and exactly match the adjacent Applied card; Blackout, Low Hold, Reveal, Sweep, and Bounce are reusable library presets; Custom means explicit values were imported or manually edited. Generated choreography intentionally stores explicit pan, tilt, dimmer, rhythm, and shutter values rather than pretending each context-aware combination is one of the five library presets.

Top-bar **Regenerate song** applies the highest-ranked context-aware choice to every cue as one atomic operation. Adjacent beat-driven cues become continuous rhythm runs: full cycles span dimmer and short intensity-accent boundaries without restarting, while an incomplete tail settles at the stable pose; fixture-chase tails complete the next fixture only when at least 200 ms remains. Lit choices use a full-output base and derive contrast from fades and curves: simple pulses are common, Flash is occasional punctuation, Textured Pulse is reserved for syncopated/orbit contexts, and Rise and Hold carries most short accents. Structural opening, transition, and ending rests become true zero-dimmer, closed-shutter blackouts. The footer reports the applied cue count, average confidence, and energy distribution. Top-bar **Undo regeneration** restores the exact cue sheet from before the most recent cue or whole-song regeneration. Choices are deterministic and explainable rather than opaque AI output.

After whole-song regeneration, each cue shows an **Applied** card containing the exact choice and settings written during that pass. The numbered **Alternatives now** are ranked again against the completed neighboring choreography, so their order or transition endpoints can differ from the applied choice. Editing a cue removes its applied attribution rather than leaving stale metadata visible.

XSQ timing tracks are classified into beat, tempo, section, phrase, and marker tracks. The timeline displays the chosen beat/downbeat source and layer-0 phrase labels and supports beat or bar snapping. Clicking a cue block seeks to its start, enables selected-cue looping, and begins preview playback; clicking another block switches the running loop. Play/Pause is the global transport: starting with Play leaves cue-loop mode and continues through the full sequence, while the Loop button controls explicit loop mode.

The timeline playhead, beat/downbeat grid, phrase labels, waveform, and click-to-seek behavior all use the rendered cue geometry. This keeps them aligned even when very short cues use a readable minimum width and make the timeline horizontally scrollable.

If the sequence audio path is unavailable, click the red **Relink audio** control and choose a local audio file. Decoding, waveform reduction, and playback stay inside the local browser process; the selected path is not written into the source sequence.
